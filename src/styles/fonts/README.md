# Nohemi Font Files

Typography configuration for DataTalk AI.

Font Family: Nohemi (Pangram Pangram)
Weights used:
- Regular (400): `Nohemi-Regular.woff2`
- Medium (500): `Nohemi-Medium.woff2`
- SemiBold (600): `Nohemi-SemiBold.woff2`

Fallback Stack:
`"Nohemi", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`

Monospace Stack (SQL / Numeric / Code):
`ui-monospace, "JetBrains Mono", Consolas, monospace`
